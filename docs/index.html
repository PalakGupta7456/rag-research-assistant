    How it works

    Every day, in GitHub Actions

    1. Fetch the newest papers in cs.LG, cs.CL, cs.AI, cs.CV, cs.IR and stat.ML from the arXiv API, keeping a rolling corpus.
    2. Embed title and abstract with all-MiniLM-L6-v2 (384 dimensions).
    3. Quantise vectors to int8. The index is about 4× smaller, with cosine error under 0.06.
    4. Benchmark BM25, dense, hybrid and cross-encoder re-ranking, then publish the index to this page.

    When you ask, in your browser

    1. BM25 keyword scores over the corpus.
    2. Your question is embedded by the same model running in WebAssembly through Transformers.js.
    3. The two rankings are merged with Reciprocal Rank Fusion.
    4. The sentences closest to your question are pulled from the top papers and cited. Claude can optionally write a fuller answer, restricted to those sources.

    The Python package adds a FastAPI service (/search, /ask) in Docker with a cross-encoder re-ranker and server-side Claude answers.
